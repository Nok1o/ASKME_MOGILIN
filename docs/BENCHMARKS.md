# Нагрузочные замеры

Каталог `benchmarks/` содержит сохранённые результаты сравнения нескольких схем
отдачи статических и динамических ответов:

- `static_wsgi.py` — простой WSGI-ответ для базового сравнения;
- `static_gunicorn.txt`, `static_nginx.txt` — статические ответы;
- `dynamic_gunicorn.txt`, `dynamic_uncached_nginx.txt` — динамические ответы;
- `dynamic_cached_nginx.txt` — эксперимент с nginx proxy cache;
- `results.txt` — исходное текстовое резюме эксперимента.

По сохранённому резюме nginx быстрее WSGI при отдаче статики, а proxy cache даёт
крупный выигрыш на повторяемом динамическом ответе. Эти цифры относятся к
конкретной машине и конфигурации, поэтому не являются универсальной гарантией.

## Воспроизводимость

Для нового сравнения фиксируйте рядом с результатом:

- дату, ОС и характеристики машины;
- версии nginx, Gunicorn и Python;
- точную команду генератора нагрузки;
- concurrency, число запросов и прогрев;
- конфигурацию кэша и размер ответа;
- среднее, медиану, p95/p99 и долю ошибок.

Не включайте proxy cache для страниц, зависящих от сессии, без корректного cache
key и bypass-правил: иначе ответ одного пользователя может получить другой.
Текущий [`askme.conf`](../askme.conf) кэширует только статические файлы.
