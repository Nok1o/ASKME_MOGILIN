# Архитектура

## Обзор

AskMe — серверное монолитное Django-приложение. Django формирует HTML, хранит
состояние в реляционной базе и обрабатывает небольшие AJAX-запросы для голосов.
В production-like схеме nginx отдаёт статику и загрузки, а остальные запросы
проксирует в Gunicorn.

```text
Browser
  ├─ /static, /uploads ───────────────> nginx ─────> filesystem
  └─ HTML and AJAX ───────────────────> nginx ─────> Gunicorn
                                                     └─ Django
                                                        └─ SQLite/PostgreSQL
```

## Компоненты

| Каталог | Ответственность |
|---|---|
| `app/models.py` | сущности, связи и выборки вопросов/ответов |
| `app/forms.py` | валидация и создание доменных объектов |
| `app/views.py` | HTTP-сценарии, пагинация и AJAX-обработчики |
| `app/urls.py` | публичные маршруты приложения |
| `templates/` | серверный пользовательский интерфейс |
| `static/` | исходные CSS, JavaScript и изображения |
| `askme_mogilin/` | конфигурация и точки входа Django |

## Модель данных

- `User` — стандартный пользователь Django.
- `Profile` — аватар, никнейм и описание пользователя; связь один-к-одному.
- `Question` — вопрос автора, связанный с несколькими `Tag`.
- `Answer` — ответ пользователя на один вопрос.
- `LikeQuestion` / `DislikeQuestion` — голос пользователя за вопрос.
- `LikeAnswer` / `DislikeAnswer` — голос пользователя за ответ.

Поля `num_likes` и `num_answers` являются денормализованными счётчиками для
быстрой выдачи. Код, изменяющий голоса или ответы, должен обновлять их вместе с
основными записями.

## Основные HTTP-маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | новые вопросы |
| GET | `/hot/` | вопросы по рейтингу |
| GET, POST | `/question/<id>` | вопрос, ответы и добавление ответа |
| GET | `/tag/<name>` | вопросы по тегу |
| GET, POST | `/ask/` | создание вопроса |
| GET, POST | `/login/`, `/signup/` | аутентификация |
| GET, POST | `/profile/edit/` | настройки профиля |
| POST | `/question/<id>/feedback` | голос за вопрос |
| POST | `/answer/<id>/feedback` | голос за ответ |
| POST | `/answer/<id>/correct` | отметка правильного ответа |

AJAX-запросы используют сессионную аутентификацию Django и CSRF-токен.

## Границы и дальнейшее развитие

Текущая структура подходит для учебного монолита. При росте проекта следующими
логичными шагами будут транзакционное обновление счётчиков, ограничения
уникальности голосов на уровне базы, сервисный слой для голосования, объектное
хранилище загрузок и полноценный набор тестов прав доступа.
